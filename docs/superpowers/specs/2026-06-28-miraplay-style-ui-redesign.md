# MiraPlay Style IPTV UI Redesign

Date: 2026-06-28

## 背景

当前 App 已经有配置导入、站点搜索、播放入口等基础能力，但 UI 信息架构不对：搜索、结果、详情和播放器被挤在同一个发现页里，导致首页像工具面板，不像一个视频播放器。

这次重构优先解决页面逻辑和视觉结构，功能适配继续沿用现有能力，不在本轮扩大第三方插件运行时范围。

## 目标

把 App 改成接近参考图的 MiraPlay 风格：

- 发现页是内容流，只展示热播海报和基础分类。
- 首页顶部左侧选择源，右侧只保留搜索入口。
- 首页搜索先弹出搜索框，提交后跳转到独立点播搜索页。
- 点播搜索页左侧显示来源分类，右侧显示海报结果。
- 海报详情页按参考图三：大背景、播放按钮、简介、线路和剧集。
- 选择播放项后弹出横屏播放器。

## 页面结构

### 1. 发现页

发现页只负责展示内容，不展示复杂搜索结果。

布局：

- 顶部左侧：源/首页选择胶囊按钮，例如 `豆瓣首页` 或当前配置源名称。
- 顶部右侧：两个圆形或胶囊按钮，主按钮为搜索；另一个可保留为快捷入口或后续扩展。
- 分类横向 Tab：`热门内容`、`热门电视`、`热门综艺`、`电影`、`电视` 等。
- 筛选 Chips：`排序`、`热度`、`最新`、`评分`、`地区`、`全部`、`华语`、`欧美`、`韩国`、`日本`。
- 主体：3 列海报网格，显示海报、评分角标和标题。
- 底部：浮动胶囊导航，包含 `发现`、`追剧`、`设置`。

数据：

- 本轮先使用可控的豆瓣热播样式数据或现有本地演示数据撑起 UI。
- 后续再接真实豆瓣/聚合内容流，不阻塞 UI 重构。

### 2. 搜索弹窗

从发现页点击搜索时，不直接在首页展开结果，而是打开轻量搜索弹窗。

交互：

- 弹窗包含一个输入框和搜索按钮。
- 输入关键词后提交，跳转到点播搜索页。
- 默认搜索范围是全部已导入源。
- 空关键词显示中文提示，不跳转。

### 3. 点播搜索页

点播搜索页是搜索结果的主工作区。

顶部：

- 左侧：返回按钮，回到发现页。
- 中间：搜索框，显示当前关键词，可直接改词重新搜索。
- 右侧：配置源选择按钮。

源选择：

- 支持多选配置接口或站点。
- 默认选择全部可用源。
- 用户取消某些源后，搜索只请求选中的源。

主体：

- 左侧来源分类栏：显示 `全部 (43 / 47)` 和每个来源名称、结果数量。
- 右侧结果区：2 列海报网格。
- 点击左侧来源时，右侧只显示该来源结果。
- 搜索失败或不兼容的源仍保留在左侧，用明确状态提示，不影响其他源结果。

### 4. 海报详情页

点击搜索结果海报后进入详情页，视觉参考图三。

布局：

- 深色全屏背景，顶部左侧返回按钮。
- 上半区使用海报或背景图做大视觉。
- 中间显示片名、年份、类型、时长、清晰度等信息。
- 主播放按钮显示当前默认线路和播放项。
- 下方显示搜索、收藏、更多等图标按钮，先做 UI 状态。
- 简介区域显示剧情简介，超长文本截断。
- 线路区域显示当前来源名称，可切换线路。
- 剧集/播放项区域显示按钮网格或横向卡片。

交互：

- 点击主播放按钮播放默认第一集或当前选中项。
- 点击某个剧集/播放项后解析最终播放地址。
- 解析失败时停留在详情页并显示中文错误。

### 5. 横屏播放器

播放器从详情页打开，作为独立横屏播放层。

行为：

- 进入播放时弹出横屏播放器。
- 退出播放器后回到详情页。
- 播放器只接收最终可播放 URL，不直接处理搜索或站点解析。
- 直播/点播直链仍使用现有 `expo-video` 播放能力。

## 导航状态

本轮可以先用 App 内部页面状态实现，不强行引入复杂路由：

- `discover`
- `searchOverlay`
- `searchResults`
- `detail`
- `player`
- `settings`
- `following`

当页面逻辑稳定后，再评估是否拆成 Expo Router 页面。

## 错误状态

- 搜索空关键词：`请输入搜索关键词`
- 未选择源：`请选择至少一个配置源`
- 全部源搜索失败：`所有来源都暂时不可用，请稍后重试`
- 单个源失败：在左侧来源栏显示失败状态，不清空其他结果。
- 详情解析失败：`详情解析失败，请换一个来源试试`
- 播放地址解析失败：`没有解析到可播放地址`
- 需要网盘账号：`该线路需要网盘账号或扫码登录`

## 测试计划

- 首页打开后只显示热播内容流，不显示旧的工具面板式搜索结果。
- 点击首页搜索出现弹窗，输入关键词后跳转搜索页。
- 搜索页顶部返回、搜索框、源选择按钮位置正确。
- 搜索页左侧来源栏和右侧海报结果在 iPhone 小屏不重叠。
- 点击海报进入详情页，详情页样式接近参考图三。
- 点击播放项打开播放器，退出后回到详情页。
- 运行现有单元测试和 Expo iOS 导出检查。

## 验收标准

- 首页第一眼像视频内容 App，而不是配置工具。
- 搜索结果不再堆在发现页。
- 用户能按 `首页 -> 搜索 -> 结果 -> 海报详情 -> 横屏播放` 的路径理解 App。
- 源选择、搜索范围和结果来源分类在视觉上清楚。
- UI 先接近参考图，再继续补功能和第三方插件兼容。
